# Holocomm design tokens

This package builds the CSS custom properties used by the frontend. Primer is
the design system and public semantic vocabulary; Holocomm does not mirror its
tokens behind an application-specific alias layer.

## Sources

1. `dtcg-examples/github-primer` supplies Primer base, functional, and component
   tokens in DTCG format.
2. `tokens/product.json` contains only decisions that Primer cannot express:
   application-shell dimensions, room-specific composite effects, theme-picker
   previews, and the chosen system font stack.
3. `tokens/primer-light.json` and `tokens/primer-dark-dimmed.json` are adapter
   compatibility patches. They restore theme values and alpha channels that the
   current DTCG conversion does not preserve. They also contain a few deliberate
   contrast and interaction adjustments, including a backdrop that visibly
   darkens the page behind dialogs.
4. `generated/tokens.css` is the generated artifact consumed by the frontend.

Frontend styles use Primer roles directly, for example `--fg-color-default`,
`--bg-color-muted`, `--button-primary-bg-color-hover`, and
`--control-track-bg-color-rest`. Product tokens such as
`--layout-app-navigation` are appropriate only where Primer has no corresponding
concept.

## Choosing a token

- Prefer a functional token such as `fgColor.muted` or `bgColor.default`. It
  describes intent and is designed to work across themes.
- Use a component token such as `button.primary.bgColor.hover` when the element
  is that Primer component and needs its exact state treatment.
- Use base size and typography scales for ordinary dimensions and text. Do not
  use base palette colors in application styles.
- Add a product token only for a genuinely Holocomm-specific decision. Give it a
  `$description`, name it from broad to specific, and use a typed DTCG value.
- Do not add a product alias for an existing Primer token. Aliases hide the
  official vocabulary without adding meaning.
- Pair semantic foreground and background roles and check them in both themes.
  Red is reserved for destructive actions and errors.
- Do not put raw colors, shadows, or `color-mix()` expressions in component
  styles.

Terrazzo emits lowercase kebab-case CSS names, so the Primer token ID
`fgColor.default` becomes `--fg-color-default`. This spelling is generated by
the CSS plugin; it is not a separate Holocomm semantic layer.

## Adapter compatibility

Primer's published source is not DTCG. The `dtcg-examples` package is the
Terrazzo-compatible adapter, but it does not apply every custom theme override
and loses some alpha metadata stored outside standard DTCG color values. The two
`primer-*.json` files patch those exact Primer paths until the adapter can
preserve them itself. They must not introduce Holocomm aliases.

Tests rebuild the tokens before checking references separately in each theme,
frontend token usage, and the contrast of important foreground/background pairs.
The button labels use the 4.5:1 minimum for normal-sized text, including hover
and active states.

## Commands

Run from this package directory:

```sh
aube run build
aube run test
```

Commit `generated/tokens.css` whenever token sources change.
